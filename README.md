# Employee Salary & Department Analysis using SQL

## Project Overview

This project analyzes employee salary and department data using SQL. The goal is to answer common business questions related to employee salaries, departments, employee distribution, and salary patterns.

The project uses SQL concepts such as filtering, aggregate functions, GROUP BY, HAVING, JOINs, CASE WHEN, subqueries, CTEs, and window functions to generate meaningful insights from the data.

## Objectives

* Analyze employee salary patterns.
* Compare salaries across departments.
* Identify high- and low-paid employees.
* Analyze employee distribution across cities and departments.
* Categorize employees based on salary.
* Identify top-performing salary groups.
* Practice real-world SQL analysis techniques.
